# Quantum Computing Atelier — Enhanced JSX

Interactive React + Vite + JSX quantum computing learning laboratory.

## Run

```bash
npm install
npm run dev
```

## Main features

- Responsive quantum-themed UI
- Interactive Bloch sphere
- Gate simulator with changing probabilities
- Live single-qubit circuit builder
- Two-qubit entanglement demonstrator
- Superposition experiment
- CNOT visualization
- Bell-state visualization
- Step-by-step teleportation
- Grover amplitude amplification demo
- QFT conceptual visualization
- Interactive quantum hardware architecture
